# Owner Bind Boundary

Owner Bind is the separately approved transition from a Neutral Golden Starter
to one owner-specific Core.

It may select or create only the owner-specific material required for that one
Core, such as identity, keys, access principals, policy, recovery arrangement,
and later owner data. It must be reviewed independently of image import,
data-empty boot, or a synthetic proof.

Before Owner Bind, do not create or select:

- an owner identity or Core data;
- keys, credentials, authorization grants, or device records;
- owner policy, recovery material, domains, endpoints, or public access;
- source records, connector state, application networking, or personal data.

A recovery snapshot is not a Neutral Golden Starter. Never use one owner's
snapshot as another owner's starting point. Start every independent owner from
the data-empty Starter image.
